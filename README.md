Entre os módulos desenvolvidos estão:

Aplicação de produtividade trabalhando hábitos, tarefas e ocorrências como entidades diferentes, evitando regras frágeis e duplicação de dados.

## 🏗️ Como penso software

```text
Problema real
    ↓
Regra de negócio
    ↓
Domínio e arquitetura
    ↓
Modelo de dados
    ↓
Segurança e permissões
    ↓
API / serviços
    ↓
UX e interface
    ↓
Testes e observabilidade
    ↓
Deploy e evolução contínua
```

Busco evitar soluções que funcionam apenas no cenário ideal. Prefiro construir uma base que continue compreensível e segura conforme o produto cresce.

Princípios que tento aplicar no dia a dia:

- **simplicidade antes de complexidade**
- **tipagem forte e contratos claros**
- **separação de responsabilidades**
- **segurança desde a modelagem**
- **RLS e autorização no backend, nunca só no frontend**
- **migrations incrementais e não destrutivas**
- **componentes reutilizáveis**
- **testes para regras críticas de negócio**
- **mobile-first quando o contexto operacional exige**
- **IA como ferramenta do produto, não como remendo arquitetural**
